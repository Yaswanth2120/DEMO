# Discipline pages

On the dev branch, the five hero nodes open /science, /engineering, /research, /material, and /eco. Each page keeps the hero animation and its discipline headline, with three focus areas, an approach, application topics, and a project enquiry link below. The general capabilities, method, industry grid, and collaboration sections are rendered only on the homepage.

Click the selected discipline again to return to / and the original Innovate beyond boundaries headline. Switching disciplines updates browser history without remounting the hero graphic. Direct URLs, refresh, Back/Forward, authentication return paths, mobile layouts, and light/dark themes are supported. Header and footer navigation adapt to the discipline content; search can navigate back to homepage sections.

The homepage collaboration section is /#partners; /research is now the dedicated research discipline page. /collaboration redirects to /#partners.

All discipline copy is a demo based on the published service scope. Program-specific methods and deliverables are agreed with the team.
